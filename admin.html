เข้าสู่ระบบหลังบ้าน

เพิ่มข่าว แบนเนอร์ และโฆษณา ต้องเข้าสู่ระบบก่อน

ตั้งค่ากุญแจบันทึกข้อมูล (ครั้งเดียวต่อเครื่อง)

เว็บนี้ไม่มีเซิร์ฟเวอร์ ข่าวและโฆษณาบันทึกลง GitHub ของเว็บ ต้องใช้ “กุญแจ” (GitHub token) ที่เข้าถึงได้เฉพาะ repo นี้ — กุญแจเก็บในเครื่องนี้เท่านั้น ไม่ถูกส่งไปที่อื่นนอกจาก GitHub

  1. เปิด สร้าง Fine-grained token (ล็อกอินบัญชีเจ้าของเว็บ)
  2. Repository access → Only select repositories → เลือก nongbuainsider
  3. Permissions → Contents: Read and write และ Issues: Read and write
  4. กด Generate token แล้วคัดลอกมาวางด้านล่าง
